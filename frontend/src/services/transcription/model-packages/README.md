# Imported model packages

The importer places validated, sealed JSON descriptors here. Vite discovers the
same data for product evaluation and app adoption. Model files remain pinned
assets; this directory never supplies executable adapter code.

Supported package profiles initially reuse the installed Xenova Whisper,
Granite CTC, and strict Parakeet WASM/int8 adapters. Unknown architectures,
tokenizers/frontends or runtime ABIs are refused, not guessed. Registration
does not authorize production activation. See scripts/model-evaluator/README.md.
